無料デプロイ（Netlify）

1. GitHub にプロジェクトを push
2. app.netlify.com でリポジトリを接続
3. 発行された https://xxxx.netlify.app を上の公開URLに入力
詳細: プロジェクト内 DEPLOY.md を参照

公開URL（埋め込み先のベース）

このサイト自体が制作サーバーです。通常は下のURL（このサイトのトップ）のまま「URLを保存」してください。発行した iframe は同じドメインで再生されます。

クラウド本番では自動でこのサイトのURLが入ります。別ドメイン（Netlify 視聴専用など）に載せる場合だけ変更してください。

⚠ localhost のURLは他の人のPCでは開けません。デプロイ後のURLを設定してください。
